# Калькулятор НДС по странам мира (Django)

Веб-приложение для расчёта НДС, сравнения ставок и визуализации данных. 
Проект переписан с Flask на Django с использованием базы данных SQLite.

## Возможности
- Живой поиск по 171 стране (с учётом синонимов и опечаток).
- Расчёт НДС «сверху» (начисление) и «из суммы» (выделение).
- Интерактивная карта мира с цветовой индикацией ставок (Plotly.js).
- Графики сравнения стран, распределения ставок и топ-5 (Chart.js).
- Справка по областям применения (льготы, пониженные ставки, экспорт).
- Сохранение истории расчётов в базу данных.
- Админ-панель Django для управления ставками и просмотра статистики.

## Технологии
- Python 3
- Django
- SQLite (база данных)
- Chart.js (графики)
- Plotly.js (карта)

## Как запустить локально
1. Клонируйте репозиторий:
   `git clone https://github.com/Alex13651/nds_calculation.git`
2. Перейдите в папку:
   `cd nds_calculation`
3. Создайте виртуальное окружение:
   `python3 -m venv .venv`
4. Активируйте его:
   `source .venv/bin/activate`
5. Установите зависимости:
   `pip install django`
6. Примените миграции (создайте БД):
   `python manage.py migrate`
7. Импортируйте страны в базу:
   `python manage.py import_data`
8. Запустите сервер:
   `python manage.py runserver`
9. Откройте в браузере `http://127.0.0.1:8000/`

## Админка
Доступна по адресу `http://127.0.0.1:8000/admin/`. 
Для входа создайте суперпользователя: `python manage.py createsuperuser`.

## Важно
Данные о ставках носят справочный характер и могут устаревать. 
Перед реальными расчётами сверяйтесь с официальными источниками.
